How I maximize my productivity on MacOS, roughly in order of importance:

- Use [Homebrew](https://brew.sh) to install and manage software.
  - See my [Brewfile](https://github.com/dcchambers/dotfiles/blob/master/mac-config/Brewfile) to learn what I have installed on my Mac.
- Use [Raycast](https://www.raycast.com/). Probably the biggest productivity upgrade you can get - and it's free.
  - Replace Spotlight Search with something far better.
  - Access to a massive library of extensions.
  - Use the [Quicklinks](https://www.raycast.com/core-features/quicklinks) feature
  - Use the excellent built-in calculator
  - Use the clipboard history
  - Use the snippets
- Use [Rectangle](https://rectangleapp.com/) for window management.
